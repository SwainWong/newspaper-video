# BGM、动效声音与配音

参考 SwainWong Video Factory 的 roles/12-bgm/METHOD.md 与动画/声音合同；本 Skill 保持跨平台可执行，不依赖插件必须安装，也不宣称内置音乐搜索服务。

输入为批准脚本、情绪段落、实测配音时码、动画事件与使用许可。输出为独立 VO/SFX/BGM 轨、最终混音、music-cues 与 sfx-cues 使用表。表记录文件/哈希、来源、许可/署名、入出点、增益、淡入淡出、循环接续、ducking（旁白时降低音乐）、试听结论。BGM 必须纳入制作，只有用户明确要求无音乐才能免除；不能用音量为零的文件冒充配乐。

按叙事设计音乐：钩子制造紧张，品牌过渡轻收，解释段降低密度，转折适度提升，片尾落稳。优先无歌词、弱中频旋律的配乐，避免与英语人声抢频；比较少量候选并记录选择原因。不得把“免费”当许可；保存实际许可范围与使用时间。若来源未取得，只能标未完成，不能承诺已具备公开使用权。

动画事件表先记录动作、开始、接触/落稳、结束，再绑定 SFX：照片飞入可用轻 whoosh，落稳配短而轻的纸张/钝击，翻页用纸声，重要关系连线用克制提示音。同一动作组可共用一个声音，不给每个字、每个微抖动都加撞击声。声锚应落在视觉接触/落稳帧，不机械放在场景第一帧。没有声效的主要动作必须说明原因。SFX 尾音不得被场景边界硬切。

旁白优先。BGM 比旁白低约 10–16 dB 可作为试混起点，SFX 在重音、姓名、关键数字处避让；这不是统一合格阈值。用淡化/包络降低干扰，音乐密度比单纯减音量更重要。试听至少覆盖口播密集、稀疏、转场、片尾并最终全片听审；响度、峰值、波形只能作为技术检查。可从 -16 至 -14 LUFS、真峰值 ≤ -1 dBTP 试起，按平台及真实听感调整。

模板现有 `music` / `musicVolume`、每镜 `audio` 和 `sfx[{file,at,gain}]` 分轨接口。1.4 增加全片帧时码 `musicEnvelope:[{frame:0,gain:0.5},{frame:30,gain:0.2},...]`，至少两点、严格递增，gain 为 0–1，在线性插值后乘 musicVolume 与首尾淡化。它是编辑安排的 ducking，不是自动识别语音侧链；必须根据实际 VO 排布。复杂跨曲接续先输出独立 BGM stem，再由 `music` 导入。输出 stem 可保留重新编辑。
